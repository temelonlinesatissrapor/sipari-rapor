GitHub bağlantısı

Bağlantı kurulursa düzeltmeler tek tıkla, doğrudan sitenize kaydedilir. Kurulmazsa duzeltmeler.json dosyası iner ve onu docs/data klasörüne siz yüklersiniz. Anahtar yalnızca bu tarayıcıda saklanır.

Erişim anahtarı nasıl alınır?
  1. GitHub'da sağ üstteki profil resminiz → Settings → en altta Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Ad verin (ör. "rapor düzeltme"), süreyi seçin.
  3. Repository access: Only select repositories → rapor deponuzu seçin.
  4. Permissions → Repository permissions → Contents: Read and write.
  5. Generate token deyin, çıkan anahtarı kopyalayıp yukarıya yapıştırın.

Geçmiş yıl ekle

Aylık özet Excel'inizi seçin. Dosya yalnızca bu tarayıcıda okunur, hiçbir yere gönderilmez.

  1. İnen gecmis.json dosyasını GitHub'da docs/data klasörüne yükleyin (klasöre girip Add file → Upload files).
  2. Yayın bitince (1–2 dakika) sayfayı yenileyin; yıl karşılaştırmada görünür.

Dosya rapor verileriyle aynı şifreyle şifrelenir; repoda açık halde durmaz. Daha önce eklenen yıllar dosyada korunur.

Henüz geçmiş yıl verisi yok

Karşılaştırma için en az iki yıllık veri gerekir. Geçmiş yılın aylık özet Excel'ini Geçmiş yıl ekle düğmesiyle ekleyin ya da Entegra'dan geçmiş siparişleri çekin.
